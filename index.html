Important limitations

This is a functional browser-based prototype, not a secured production deployment.
  • Data is stored in this browser's local storage and can be lost if site data is cleared.
  • Facial recognition can make mistakes. Teacher review is required for uncertain results.
  • Obtain appropriate consent and follow applicable privacy, education, and biometric-data rules before using with real students.

Twins & similar-face safeguard
When enabled, close face matches are sent to teacher review instead of guessing. The teacher must select the student and verify their student ID before attendance is recorded.
Session safety: Reprocessing the same class/session on the same date will not create duplicate student attendance records. Use a distinct session name for a separate class.
Verification details: Results show face-detection quality and closest registered candidates where relevant. Detection quality is not identity confidence; matching thresholds should be validated on representative images before real-world use.
Automatic attendance is limited to confident, unambiguous matches. With extra-cautious matching enabled, close candidates (including possible twins) are sent to teacher review. The teacher must select a candidate and verify the student ID; a face with no confident match is not marked present.
